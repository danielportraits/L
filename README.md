# LIDA - Secure Gothic/Neon PWA

Aplicación web progresiva (PWA) de alta fidelidad con estética gótico-neón, mensajería instantánea cifrada (E2EE), notas de voz estilo WhatsApp, historias, reels, videollamadas con filtros WebGL en tiempo real y juegos multijugador 1v1 con historial H2H, integrados con **Supabase**.

## 🚀 Instalación y Ejecución Local

1. Clona el repositorio.
2. Instala las dependencias:
   ```bash
   npm install
   ```
3. Configura tus variables de entorno en un archivo `.env` basado en `src/supabaseClient.js`.
4. Inicia el servidor de desarrollo:
   ```bash
   npm run dev
   ```
5. Abre `http://localhost:3000` en tu navegador.
